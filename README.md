# blog-posts

블로그 포스트 저장용

submodule로 블로그에서 포스트를 추가하고 가져다 사용한다.

1. submodule에서 포스트 작성
2. blog에서 submodule 포스트를 패치
3. 빌드 & 업로드

## 서브 모듈 이용 방법

### 서브 모듈 설치 방법

```bash
git submodule add [깃 주소] articles
```

### 서브 모듈 패치 방법

```bash
git submodule update --remote
```

## 글쓰기 전 자료조사

스킬: [raw-research](.agents/skills/raw-research/SKILL.md)

예시 요청:

> web-audio-1 글 쓰기 전에 raw-research로 자료조사해줘.

웹 자료와 논문을 검색하고, 자료 신뢰도 평가와 주장별 팩트 체크를 수행한다.
중복 자료와 주제 밖 내용을 제거한 결과를 대상 포스트 폴더의 `search.md`에 별도 승인 없이 바로 저장한다. 사용자의 상시 승인은 이 자료조사 파일의 생성·갱신에만 적용한다.

- 자료 신뢰도: `높음`, `보통`, `낮음`, `판단 불가`. 출처의 명성만이 아니라 원출처, 방법, 적용 조건, 검증 상태, 시점·버전, 이해관계를 평가하고 판단 이유를 남긴다.
- 주장별 판정: `교차 확인`, `단일 출처`, `조건부`, `상충`, `미확인`. 신뢰도 높은 자료 하나만 있으면 독립적인 교차 확인으로 취급하지 않는다.
- 출력: 조사 범위, 핵심 조사 내용, 팩트 체크, 주의·추가 확인, 출처, 검색 기록.
- 보호 범위: 기존 사용자 메모를 보존한다. `index.mdx`, 이미지, 다른 포스트, wiki는 수정하지 않으며 포스트 폴더 생성·발행·자동 커밋·푸시도 하지 않는다.
