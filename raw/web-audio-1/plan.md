# 가청영역 시각화 계획

## 핵심 메시지

사람이 들을 수 있는 주파수의 범위와 여러 소리의 대표 대역을 구간별 선형 축에서 비교한다. 낮은 주파수를 구분하기 위해 데이터가 없는 1~4 kHz 구간은 물결표시로 생략한다.

## 화면 구성

1. 제목과 짧은 질문으로 주제 소개
2. 왼쪽에 비교 대상과 대표 범위를 표시
3. 가청주파수, 피아노 최저음, 전기 제품의 ‘웅—’ 소리, 조율 기준음, 피아노 최고음, 오래된 TV의 ‘삐—’ 소리, 개 휘파람 비교
4. 아래쪽에 0~1 kHz와 4~25 kHz 선형 구간을 표시하고 사이에 축 생략 물결표시 추가

## 색상

- 배경: 짙은 남색
- 비교 대역: 소리마다 서로 다른 색상
